How to Publish Changes (Step-by-Step)

Follow these simple steps whenever you add, edit, or delete an answer:

  1. Make changes: Use the "Add New Answer", "Edit", or "Delete" buttons above.
  2. Verify: Click "Validate Data" to confirm there are no errors or broken topic links.
  3. Download: Click "Download qa.json" (and "Download topics.json" if you added a new topic).
  4. Replace files: Move the downloaded file(s) into the data/ folder on your computer, replacing the old file.
  5. Deploy live: Open your terminal in the project folder and run:
    git add . git commit -m "Updated rulings and answers" git push
✓ Once you run git push, Vercel automatically deploys your updates live in 1 to 2 minutes!
